# ML/tests

Ada 36 kasus pytest. Jalankan dari folder `ML/` dengan `../.venv/bin/python -m pytest`.

Tes ini memeriksa hukum Faraday dan fisika sel, reaktor, kontroler (termasuk sensor macet, warna mentok, dan jeda surya), model dosis, model surya dan baterai, serta hasil utama analisis sensitivitas dan ketahanan. Tes yang memerlukan API dan firmware ada di `dashboard/backend/tests/`.
