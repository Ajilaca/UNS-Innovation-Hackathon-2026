# scripts

| Skrip | Isi |
|---|---|
| `demo-docker.sh` | Menyalakan seluruh stack dengan Docker. Argumen `stop` mematikan, `reset` menghapus data. Membuat `.env` bila belum ada |
| `demo-offline.sh` | Backend dan simulasi tanpa Docker. Riwayat di `/tmp` dihapus tiap kali dijalankan. `PORT` bisa diganti |

Keduanya sudah dicoba dari salinan bersih repositori di Linux.
